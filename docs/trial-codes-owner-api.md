# واجهة رموز تفعيل التجربة المجانية — دليل الدمج لموقع الأونر

\‌u202Bالوثيقة دي شرح كامل لنظام رموز تفعيل التجربة المجانية في منصة MERUNA، وهدفها إن مطور موقع الأونر يقدر يدمجها من غير الرجوع لكود المنصة: توليد رمز، تحديد مدته، متابعته، وإلغاؤه أو إنهاء تجربة شغالة في أي وقت.\‌u202C

## 1. الفكرة العامة

\‌u202Bأي عيادة جديدة بتتسجل في المنصة بتدخل على تجربة مجانية مقفولة: بتشوف جولة ترحيب إجبارية آخر بطاقة فيها إدخال رمز التفعيل، ومفيش وصول فعلي للمرضى أو المواعيد أو الشات قبل الرمز. الرمز بيصدر من المنصة فقط، بيشتغل مرة واحدة، وبيفتح تجربة مدتها بيوم محدد وقت التوليد.\‌u202C

\‌u202Cقواعد الرمز المضمونة على مستوى قاعدة البيانات:\‌u202C

- \‌u202Bالرمز بيشتغل مرة واحدة بس، ومستحيل يتقفل عليه تجربة تانية.\‌u202C
- \‌u202Bممكن يتربط ببريد العيادة اللي هيتبعتله، وساعتها أي بريد تاني بيترفض.\‌u202C
- \‌u202Bللرمز نفسه مدة صلاحية قبل الاستخدام 30 يوم من تاريخ التوليد.\‌u202C
- \‌u202Bمدة التجربة نفسها من يوم لـ 90 يوم بحد أقصى، والافتراضي 14 يوم.\‌u202C
- \‌u202Bكل عيادة ليها تجربة واحدة شغالة في نفس الوقت.\‌u202C

## 2. المصادقة

\‌u202Bكل نقاط إدارة الرموز محمية بمفتاح المنصة، وبيتبعت في الهيدر مع كل طلب:\‌u202C

```text
x-admin-key: <PLATFORM_ADMIN_SECRET>
```

- \‌u202Bقيمة المفتاح هي متغير البيئة‌‌ ‌`PLATFORM_ADMIN_SECRET`‌ ‌الموجود عند فريق المنصة.\‌u202C
- \‌u202Bالمفتاح سري ويستخدم من الخادم فقط — ممنوع يوصل لأي واجهة أمامية.\‌u202C
- \‌u202Bأي طلب بمفتاح غلط بيرجع 401.\‌u202C

\‌u202Cعنوان الـ API الأساسي في التطوير:\‌u202C

```text
http://localhost:5000/api
```

## 3. توليد رمز جديد

```text
POST /api/admin/trial-codes
```

\‌u202Cالجسم المتوقع بصيغة JSON:\‌u202C

```json
{
  "intendedEmail": "owner@clinic.com",
  "durationDays": 14,
  "note": "عيادة الأمل - الرياض"
}
```

- `intendedEmail` \‌u202Bاختياري لكن مستحب بشدة: لو اتحدد، الرمز بيشتغل بس لما المستخدم يكون مسجل دخول بنفس البريد ده، وده بيمنع مشاركة الرمز بين حسابات.\‌u202C
- `durationDays` \‌u202Bاختياري، افتراضي 14، ويتقبل من 1 لـ 90.\‌u202C
- `note` \‌u202Bاختياري، ملاحظة داخلية حرة بتظهر في قائمة الرموز.\‌u202C

\‌u202Cاستجابة نجاح 201:\‌u202C

```json
{
  "code": "MERUNA-3Z8Y-RCM4-KYA5",
  "intendedEmail": "owner@clinic.com",
  "durationDays": 14
}
```

- \‌u202Bصيغة الرمز ثابتة: بادئة MERUNA وثلاث مجموعات من أربعة محارف، من غير محارف ملتبسة زي 0 وO و1 وI.\‌u202C
- \‌u202Bخزن الرمز فور ما يرجع — مش بيتعرض تاني في نفس الشكل، بس بيظهر في قائمة الرموز.\‌u202C

## 4. قائمة الرموز

```text
GET /api/admin/trial-codes
```

\‌u202Cاستجابة نجاح 200 — آخر 50 رمز بالترتيب من الأحدث:\‌u202C

```json
{
  "items": [
    {
      "code": "MERUNA-3Z8Y-RCM4-KYA5",
      "intendedEmail": "owner@clinic.com",
      "durationDays": 14,
      "status": "used",
      "usedByClinicId": "b72f4cd3-a6a9-4f61-be64-703b443fbe7f",
      "usedAt": "2026-09-06T19:01:53.426112+00:00",
      "expiresAt": "2026-10-06T18:55:00.000000+00:00",
      "note": "عيادة الأمل - الرياض",
      "createdAt": "2026-09-06T18:55:00.000000+00:00"
    }
  ]
}
```

\‌u202Cقيم الحالة:\‌u202C

- `unused` \‌u202Bمتاح للاستخدام.\‌u202C
- `used` \‌u202Bاتستخدم وفتح تجربة.\‌u202C
- `revoked` \‌u202Bملغي نهائيًا — مش هيشتغل أبدًا.\‌u202C

## 5. إلغاء رمز أو إنهاء تجربة شغالة في أي وقت

```text
POST /api/admin/trial-codes/{code}/revoke
```

\‌u202Bسلوك النقطة حسب حالة الرمز:\‌u202C

- \‌u202Bرمز لسه متستخدمش: بيتعلّم ملغي، ومستحيل حد يستبدله بعدها.\‌u202C
- \‌u202Bرمز مستخدم وفتح تجربة: التجربة بتتقفل في نفس اللحظة — العيادة بترجع للحالة المقفولة وبتلاقي بطاقة الرمز تاني، وبتقدر تستبدل رمز جديد لو أنت وافقت.\‌u202C
- \‌u202Bحماية مهمة: لو العيادة اترقّت لاشتراك مدفوع حقيقي على Paddle، النقطة بترفض بالرسالة 409 ومش هتلمس الاشتراك المدفوع أبدًا.\‌u202C

\‌u202Cاستجابة نجاح 200:\‌u202C

```json
{
  "revoked": true,
  "terminatedTrial": true,
  "clinicId": "b72f4cd3-a6a9-4f61-be64-703b443fbe7f"
}
```

- `terminatedTrial` \‌u202Bبتكون true بس لما كان فيه تجربة شغالة اتقفلت فعليًا.\‌u202C

\‌u202Cأخطاء ممكنة:\‌u202C

- `404` \‌u202Bالرمز غير موجود.\‌u202C
- `400` \‌u202Bالرمز ملغي بالفعل.\‌u202C
- `409` \‌u202Bالعيادة عندها اشتراك مدفوع والمحاولة اترفضت.\‌u202C

## 6. استبدال الرمز من طرف العميل — للفهم فقط

\‌u202Bده مش من موقع الأونر؛ ده اللي بيحصل تلقائي داخل منصة العيادة لما صاحبها يدخل الرمز في بطاقة الترحيب:\‌u202C

```text
POST /api/billing/redeem-trial-code
```

```json
{ "code": "MERUNA-3Z8Y-RCM4-KYA5" }
```

\‌u202Cبالجلسة الشخصية للعميل، ومفيش مفتاح أدمن هنا. أخطاء الاستبدال:\‌u202C

- `invalid_code` \‌u202Bالرمز غلط أو مستخدم أو ملغي أو انتهت صلاحيته.\‌u202C
- `email_mismatch` \‌u202Bالرمز مربوط ببريد تاني.\‌u202C
- `already_active` \‌u202Bالعيادة مفعلة بالفعل.\‌u202C
- `no_clinic` \‌u202Bالحساب مش مرتبط بعيادة.\‌u202C

## 7. إيه اللي بيحصل للعيادة غير المفعلة

\‌u202Bالقفل مفروض على مستوى خادم المنصة مش الواجهة، فمفيش طريقة تتحايل عليها من المتصفح:\‌u202C

- \‌u202Cمقفول بالكامل قبل التفعيل: إنشاء وتعديل المرضى، المواعيد، صندوق الوارد، عمليات التشغيل، الاستيراد، الوكيل الصوتي.\‌u202C
- \‌u202Cمفتوح قبل التفعيل: إعدادات العيادة، الفروع، الموظفين، الأطباء والخدمات والمواعيد المتاحة، القنوات، الفوترة.\‌u202C
- \‌u202Cأي محاولة على جزء مقفول بترجع 403 بالرسالة دي:\‌u202C

```text
عيادتك غير مفعلة بعد. أدخل رمز التفعيل من لوحة عيادتك لبدء تجربتك المجانية.
```

## 8. مخطط التخزين — للمرجع

\‌u202Cالجدول‌‌ ‌`public.trial_codes`‌ ‌في Supabase:\‌u202C

```text
code            text     الرمز نفسه، فريد
duration_days   int      مدة التجربة بالأيام، من 1 لـ 90
intended_email  text     البريد المرتبط بالرمز أو فارغ
status          text     unused | used | revoked
used_by_clinic_id uuid  العيادة اللي استبدلت الرمز
used_by_user_id   uuid  المستخدم اللي استبدل
used_at         timestamptz وقت الاستبدال
expires_at      timestamptz نهاية صلاحية الرمز قبل الاستخدام، 30 يوم من التوليد
note            text     ملاحظة داخلية
created_at      timestamptz وقت التوليد
```

\‌u202Cالدوال في القاعدة:\‌u202C

- `fn_mint_trial_code(p_intended_email, p_duration_days, p_note, p_valid_days)` \‌u202Cلتوليد رمز — صلاحيتها للخدمة فقط.\‌u202C
- `fn_redeem_trial_code(p_code)` \‌u202Cلاستبدال الرمز من المستخدم — بتتحقق من الاستخدام الواحد والبريد وحالة العيادة وبتفتح فترة التجربة في جدول الاشتراكات.\‌u202C

\‌u202Cملفات الهجرات في المستودع:\‌u202C

```text
supabase/migrations/2026_09_06_trial_activation_codes.sql
```

## 9. أمثلة جاهزة للنسخ

\‌u202Cتوليد رمز 14 يوم لبريد محدد:\‌u202C

```bash
curl -X POST "$BASE/api/admin/trial-codes" \
  -H "x-admin-key: $PLATFORM_ADMIN_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"intendedEmail":"owner@clinic.com","durationDays":14,"note":"عيادة الأمل"}'
```

\‌u202Cعرض الرموز:\‌u202C

```bash
curl "$BASE/api/admin/trial-codes" \
  -H "x-admin-key: $PLATFORM_ADMIN_SECRET"
```

\‌u202Cإنهاء تجربة شغالة أو إلغاء رمز:\‌u202C

```bash
curl -X POST "$BASE/api/admin/trial-codes/MERUNA-3Z8Y-RCM4-KYA5/revoke" \
  -H "x-admin-key: $PLATFORM_ADMIN_SECRET"
```

## 10. ملاحظات دمج لموقع الأونر

- \‌u202Cخزن مفتاح المنصة في متغير بيئة على خادم الأونر، وابعت الطلبات من الخادم للمزج مع الـ API مباشرة.\‌u202C
- \‌u202Cاعرض الرمز مرة واحدة بصيغة قابلة للنسخ مع زر نسخ، واظهر حالته بعد التحديث من نقطة القائمة.\‌u202C
- \‌u202Cخلي زر الإلغاء بتأكيد مزدوج لما حالة الرمز تكون مستخدم، لأنه بيقفل تجربة شغالة فورًا.\‌u202C
- \‌u202Cالمدة الحالية للرمز قبل الاستخدام ثابتة 30 يوم. لو محتاج تتحكم فيها من الواجهة، قول لفريق المنصة يضاف كحقل في نقطة التوليد.\‌u202C
